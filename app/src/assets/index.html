SNAD dustmaps API

A small HTTP service answering dust-extinction queries: E(B−V) at a sky position, for ztf.snad.space.

See the API reference and examples.

  • GET /api/v1/csfd?ra=<deg>&dec=<deg>: 2D E(B−V), CSFD (Chiang 2023)
  • GET /api/v1/bayestar2019?ra=<deg>&dec=<deg>&distance=<pc>: 3D E(B−V), Bayestar19 (Green et al. 2019)
  • GET /api/v1/health: liveness check
